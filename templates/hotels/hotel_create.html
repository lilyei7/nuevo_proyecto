📚 Ayuda
¿Cómo obtener la URL de Booking.com?
  1. Ve a booking.com
  2. Busca y selecciona el hotel
  3. Copia la URL completa de la página del hotel
  4. La URL debe verse como: https://www.booking.com/hotel/mx/nombre-hotel.html
¿Cómo obtener los IDs de OTASync?
  • Property ID: ID de tu propiedad en OTASync (ej: 9355)
  • Pricing Plan ID: ID del plan de precios (ej: 26946)
  • Room Type ID: Opcional, para habitaciones específicas
